One funny, true line reviewing the dullest everyday object: a rubber band.

> At 7:40 this morning, Pak Budi's rubber band snapped while holding his lunchbox shut. Rice everywhere. He picked up the band first. 'Six years,' he said. 'Six good years.'

171 characters. The joke comes from how the object really behaves: a rubber
band holds on for years, then snaps without warning — and still gets picked
up first.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
